# T0019 reproduction

Run only on the measurement host from the frozen checkout under an exclusive CPU lease, with no concurrent formal GPU work. Set AI_TEST_ROOT, CXX, T0019_PYTHON and the process-scoped safe.directory for this checkout. Link data/p_only/value to the already retained earlier value-screen data for read-only diagnostics; never direct the new screen output to that shared dataset. Use corrected seed20261230; old20261220 is consumed. The helper requires its task.py lock parent and starts a passive observer. Completed stages are verified and retained. After a failure, preserve logs/state and verify identities before resuming the unfinished stage.

Measured code comes from the frozen commit, not the later report commit. Generated diagnostic executables remain in ignored build/t0019/. All report results are generated by the repository tools or the saved orchestration below; raw matches, branch roots, binaries and private host paths are excluded from delivery.

## t0019_pipeline.py

```python
"""Identity-bound T0019 diagnostics, equal-time games and branch regret on the host.

Run from the isolated frozen checkout, under its verified CPU lease.
Completed stages are retained; failures stop with their receipts intact.
"""
import collections
import copy
import gzip
import hashlib
import json
import os
import shutil
import subprocess
import sys
import time
from pathlib import Path

sys.path.insert(0, str(Path.cwd()))
sys.path.insert(0, str(Path.cwd() / 'bots/p_only/tools'))
from fusion import matchlog
from fusion.paths import engine_path, bot_path, load_pool
from training.branch_collect import root_turns
from branch_portfolio import arm_key, unit_hash

SOURCE = '05f4aca0acd2f4d31b101b9b71b4afa95c888330'
BRANCH = 'codex/t0019-search-host-evidence'
REPORT = Path('bots/p_only/report/search_portfolio')
BUILD = Path('build/t0019')
CONFIG = Path('bots/p_only/profiles/screen_search.json')
WORK = Path('data/p_only/search')
STATE = BUILD / 'pipeline_state.json'
ARMS = ['c08_search_a', 'c08_search_b', 'c08_search_c', 'c08_search_d', 'v12_search_a', 'v12_search_b']
sha = lambda p: hashlib.sha256(Path(p).read_bytes()).hexdigest()
read = lambda p: json.loads(Path(p).read_text(encoding='utf-8-sig'))
utc = lambda: time.strftime('%Y-%m-%dT%H:%M:%SZ', time.gmtime())
git = lambda *a: subprocess.check_output(['git', *a], text=True).strip()


def write(path, value):
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(value, indent=1) + '\n', encoding='utf-8', newline='\n')


def source_identity():
    assert git('rev-parse', 'HEAD') == SOURCE
    assert git('branch', '--show-current') == BRANCH
    subprocess.run(['git', 'diff', '--exit-code', '--', 'fusion', 'training', 'inference', 'roster', 'tools',
                    'bots/p_only/bots', 'bots/p_only/include', 'bots/p_only/tools', 'bots/p_only/profiles',
                    'bots/p_only/tests', 'tests', 'profiles'], check=True)
    cfg = read(CONFIG)
    assert cfg['seed'] == 20261230 and cfg['teams'] == list(range(2, 16))
    assert cfg['maps_per_count'] == 20 and cfg['workers'] == 6
    assert cfg['first_ms'] == 2000 and cfg['turn_ms'] == 50 and cfg['keep_matches']
    assert cfg['arms'] == ARMS and cfg['aa'] == ['c08_search_a', 'v12_search_a']
    paths = subprocess.check_output(['git', 'ls-files', 'fusion', 'training', 'inference', 'roster', 'tools',
                                   'bots/p_only/bots', 'bots/p_only/include', 'bots/p_only/tools',
                                   'bots/p_only/profiles', 'bots/p_only/tests', 'tests', 'profiles'], text=True).splitlines()
    pairs = [(p, sha(p)) for p in paths]
    arena = Path(os.environ['AI_TEST_ROOT'])
    roster = {e['name']: e for e in load_pool()['bots']}
    names = ['Astra', 'Sol', 'Fable', 'Sonnet', 'Opus', 'DeepSeek', 'Qwen', 'MiMo', 'Kimi', 'GLM', 'Player5', 'Baseline']
    return {'source_commit': SOURCE, 'config_sha256': sha(CONFIG), 'config': cfg,
            'tracked_measurement_sources_sha256': hashlib.sha256(json.dumps(pairs).encode()).hexdigest(),
            'policy_manifest_sha256': sha('inference/models_xxl/MANIFEST.json'),
            'engine_sha256': sha(engine_path(arena)), 'engine_commit': git('-C', str(arena), 'rev-parse', 'HEAD'),
            'roster_sources': {n: sha(bot_path(roster[n], arena)) for n in names},
            'compiler_version': subprocess.check_output([os.environ['CXX'], '--version'], text=True).splitlines()[0],
            'OMP_NUM_THREADS': os.environ.get('OMP_NUM_THREADS'), 'V_enabled': False, 'policy_family': 'p2'}


def diagnostic_inputs():
    files = [p for p in sorted(matchlog.iter_matches('data/p_only/value/matches'))
             if p.name.split('.')[0].endswith('-' + arm_key('v12_ponly_pxxl_vm'))]
    files = sorted(files, key=lambda p: unit_hash('diag', p.name))[:60]
    assert len(files) == 60, len(files)
    return [{'name': p.name, 'sha256': sha(p), 'bytes': p.stat().st_size} for p in files]


def frozen_screen():
    manifest = read('build/p_only/manifest.json')
    stable = copy.deepcopy(manifest)
    stable.pop('updated', None)
    for name, variant in stable['variants'].items():
        variant.pop('compile_seconds', None)
        assert sha(variant['binary']) == variant['binary_sha256'], name
        for item in variant['inputs']:
            assert sha(item['path']) == item['sha256'], item['path']
    assert set(stable['variants']) == set(ARMS)
    schedule = read(WORK / 'schedule.json')
    assert len(schedule['fixtures']) == 280
    assert dict(collections.Counter(x['teams'] for x in schedule['fixtures'])) == {n: 20 for n in range(2, 16)}
    return {'manifest_raw_sha256': sha('build/p_only/manifest.json'),
            'manifest_stable_sha256': hashlib.sha256(json.dumps(stable, sort_keys=True).encode()).hexdigest(),
            'manifest_stable': stable, 'schedule_sha256': sha(WORK / 'schedule.json'),
            'identities_sha256': sha(WORK / 'identities.json'), 'identities': read(WORK / 'identities.json')}


def main():
    REPORT.mkdir(parents=True, exist_ok=True)
    BUILD.mkdir(parents=True, exist_ok=True)
    baseline = source_identity()
    inputs = diagnostic_inputs()
    pre = REPORT / 'FROZEN_INPUTS.json'
    if pre.exists():
        assert read(pre) == {'measurement': baseline, 'diagnostic_inputs': inputs}, 'Input identity changed'
    else:
        write(pre, {'measurement': baseline, 'diagnostic_inputs': inputs})
    state = read(STATE) if STATE.exists() else {'task': 'T0019', 'source_commit': SOURCE, 'started_utc': utc(), 'steps': []}
    state['pid'] = os.getpid()

    def check_source():
        assert source_identity() == baseline, 'Frozen measurement source changed'
        assert diagnostic_inputs() == inputs, 'Recorded diagnostic games changed'

    def step(name, args):
        check_source()
        if any(s['stage'] == name and s['exit_code'] == 0 for s in state['steps']):
            print('Verified completed stage retained:', name, flush=True)
            return
        state['stage'] = name
        write(STATE, state)
        print(utc(), name, 'python', ' '.join(args), flush=True)
        start = time.monotonic()
        code = subprocess.call([sys.executable, *args])
        state['steps'].append({'stage': name, 'command': ['python', *args], 'exit_code': code,
                               'finished_utc': utc(), 'wall_seconds': round(time.monotonic() - start, 3)})
        write(STATE, state)
        if code:
            state['stage'] = 'failed'
            write(STATE, state)
            raise SystemExit(code)

    step('diagnostics', ['bots/p_only/tools/search_diag.py', '--matches', 'data/p_only/value/matches',
                        '--arm', 'v12_ponly_pxxl_vm', '--games', '60', '--fixed-samples', '128',
                        '--out', (REPORT / 'diag_fixed_work').as_posix()])
    diag = read(REPORT / 'diag_fixed_work.json')
    assert diag['games'] == 60 and len(diag['configs']) == 7
    assert all(v['root_digest_mismatches'] == 0 and v['turns'] > 0 for v in diag['configs'].values())
    # Diagnostic executables are local ignored artifacts, never report deliverables.
    if (REPORT / 'diag_build').exists():
        assert not (BUILD / 'diag_build').exists(), 'Keep previous diagnostic binaries before recovery'
        shutil.move(str(REPORT / 'diag_build'), str(BUILD / 'diag_build'))
    step('prepare', ['bots/p_only/tools/run_screen.py', '--config', CONFIG.as_posix(), '--dry-run'])
    frozen = frozen_screen()
    receipt = REPORT / 'FROZEN_SCREEN.json'
    if receipt.exists():
        original = read(receipt)
        assert {k: v for k, v in original.items() if k != 'manifest_raw_sha256'} == {
            k: v for k, v in frozen.items() if k != 'manifest_raw_sha256'}, 'Screen identity changed'
    else:
        original = frozen
        write(receipt, original)

    def check_screen():
        check_source()
        current = frozen_screen()
        assert {k: v for k, v in current.items() if k != 'manifest_raw_sha256'} == {
            k: v for k, v in original.items() if k != 'manifest_raw_sha256'}, 'Screen identity changed'
        return current

    step('screen', ['bots/p_only/tools/run_screen.py', '--config', CONFIG.as_posix()])
    current = check_screen()
    write(REPORT / 'MANIFEST_METADATA_RECEIPT.json', {'original_raw_sha256': original['manifest_raw_sha256'],
          'after_screen_raw_sha256': current['manifest_raw_sha256'], 'stable_sha256': current['manifest_stable_sha256'],
          'ignored_metadata_fields_only': ['updated', 'variants.*.compile_seconds']})
    screen = read(REPORT / 'screen.json')
    assert screen['fixtures'] == 280 and not screen['incomplete'] and not screen['stale_rows']
    assert set(screen['arms']) == set(ARMS + ['c08_search_a~aa', 'v12_search_a~aa'])
    assert all(v['games'] == 280 for v in screen['arms'].values())
    matches = list(matchlog.iter_matches(WORK / 'matches'))
    assert len(matches) == 2240, len(matches)
    expected_ids = {f['fixture_id'] + '-' + arm_key(a) for f in read(WORK / 'schedule.json')['fixtures']
                    for a in screen['arms']}
    actual_ids = {matchlog.load(p)['match_id'] for p in matches}
    assert actual_ids == expected_ids and len(actual_ids) == 2240
    branch_audit = {}
    for arm, compare, tag in [('v12_search_a', 'v12_search_b', 'v12'), ('c08_search_a', 'c08_search_d', 'c08')]:
        check_screen()
        directory = Path('data/branches/search_' + tag)
        step('branches_' + tag, ['bots/p_only/tools/branch_portfolio.py', '--matches', (WORK / 'matches').as_posix(),
             '--arm', arm, '--other-arms', *[a for a in ARMS if a != arm], '--compare-arm', compare,
             '--out', directory.as_posix(), '--roots-per-match', '1', '--candidates', '8', '--repeats', '2',
             '--max-matches', '200', '--workers', '6'])
        check_screen()
        step('regret_' + tag, ['bots/p_only/tools/branch_regret.py', '--branches', directory.as_posix(),
             '--arm', arm, '--compare-arm', compare, '--out', (REPORT / ('regret_' + tag)).as_posix()])
        selected = sorted([p for p in matches if p.name.split('.')[0].endswith('-' + arm_key(arm))],
                          key=lambda p: unit_hash('pick', p.name))[:200]
        expected = {(m['match_id'], t) for p in selected for m in [matchlog.load(p)] for t in root_turns(m, 1)}
        rows = []
        for p in sorted(directory.rglob('*.json.gz')):
            with gzip.open(p, 'rt', encoding='utf-8') as f:
                rows.append(json.load(f))
        actual = [(r['match_id'], r['turn']) for r in rows]
        assert set(actual) == expected and len(actual) == len(expected), tag
        summary = read(directory / 'summary.json')
        write(REPORT / ('branch_summary_' + tag + '.json'), summary)
        branch_audit[tag] = {'expected_root_keys': len(expected), 'root_files': len(rows),
                             'summary_sha256': sha(directory / 'summary.json')}
    check_screen()
    write(REPORT / 'PIPELINE_RESULT.json', {'completed_utc': utc(), 'source_commit': SOURCE, 'games': len(matches),
          'scheduled_fixture_arm_coverage': True, 'branch_root_coverage': branch_audit, 'steps': state['steps'],
          'formal_resource_policy': 'exclusive CPU lease, passive observer, no caps or paging changes',
          'production_default_changed': False})
    state['stage'] = 'complete'
    state['completed_utc'] = utc()
    write(STATE, state)
    print('T0019 stages complete; detailed independent audit, interpretation, checks and PR still required.', flush=True)


if __name__ == '__main__':
    main()
```

```powershell
$ErrorActionPreference='Stop'
$root=(Get-Location).Path
$self=Get-CimInstance Win32_Process -Filter "ProcessId=$PID"
$parent=Get-CimInstance Win32_Process -Filter "ProcessId=$($self.ParentProcessId)"
if ($parent.CommandLine -notmatch 'task.py lock.*T0019.*t0019_run.ps1') { throw 'Unverified CPU lock parent' }
$lease=Get-Content -LiteralPath (Join-Path $env:USERPROFILE '.ctf-fusion/locks/cpu.json') -Raw | ConvertFrom-Json
if ($lease.pid -ne $parent.ProcessId -or $lease.task -ne 'T0019') { throw 'Wrong CPU lease' }
if (Test-Path -LiteralPath (Join-Path $env:USERPROFILE '.ctf-fusion/locks/gpu.json')) { throw 'GPU lease present; no formal CPU/GPU concurrency' }
$created=$parent.CreationDate.ToUniversalTime().ToString('o')
@{pipeline_pid=$parent.ProcessId;created_utc=$created;source_commit='05f4aca0acd2f4d31b101b9b71b4afa95c888330';helper_pid=$PID} |
    ConvertTo-Json | Set-Content -LiteralPath 'build/t0019/pipeline_pid.json' -Encoding utf8
if (-not $env:T0019_PYTHON) { throw 'T0019_PYTHON must name the verified interpreter' }
$watch=Start-Process -FilePath 'pwsh.exe' -ArgumentList @('-NoProfile','-ExecutionPolicy','Bypass','-File','../../t0019_resource_monitor.ps1',
    '-RepoPath',$root,'-PipelinePid',[string]$parent.ProcessId,'-CreationUtc',$created,'-ExpectedCommandTag','t0019_run.ps1') `
    -WindowStyle Hidden -RedirectStandardOutput 'build/t0019/resource_monitor.stdout' `
    -RedirectStandardError 'build/t0019/resource_monitor.stderr' -PassThru
@{monitor_pid=$watch.Id;created_utc=$watch.StartTime.ToUniversalTime().ToString('o');pipeline_pid=$parent.ProcessId} |
    ConvertTo-Json | Set-Content -LiteralPath 'build/t0019/resource_monitor_pid.json' -Encoding utf8
& $env:T0019_PYTHON ../../t0019_pipeline.py
exit $LASTEXITCODE
```

## t0019_resource_monitor.ps1

```powershell
param([Parameter(Mandatory=$true)][string]$RepoPath,
      [Parameter(Mandatory=$true)][int]$PipelinePid,
      [Parameter(Mandatory=$true)][string]$CreationUtc,
      [ValidateSet('t0019_pipeline.py','t0019_run.ps1')][string]$ExpectedCommandTag='t0019_pipeline.py')
$ErrorActionPreference='Stop'
$root = (Resolve-Path -LiteralPath $RepoPath).Path
$output = Join-Path $root 'build/t0019'
$expected = [datetime]::Parse($CreationUtc).ToUniversalTime()
$encoding = [System.Text.UTF8Encoding]::new($false)
function Write-Sample($row) {
    $json = $row | ConvertTo-Json -Depth 5 -Compress
    [System.IO.File]::WriteAllText((Join-Path $output 'resource_state.json'),$json+"`n",$encoding)
    [System.IO.File]::AppendAllText((Join-Path $output 'resource_monitor.jsonl'),$json+"`n",$encoding)
}
while ($true) {
    try {
        $all = @(Get-CimInstance Win32_Process)
        $pipeline = $all | Where-Object ProcessId -eq $PipelinePid
        $utc = (Get-Date).ToUniversalTime().ToString('o')
        if (-not $pipeline) { Write-Sample @{utc=$utc;event='pipeline_exited';pipeline_pid=$PipelinePid}; break }
        if ([math]::Abs(($pipeline.CreationDate.ToUniversalTime()-$expected).TotalSeconds) -gt 1 -or
            $pipeline.CommandLine -notmatch ('task.py lock.*T0019.*'+[regex]::Escape($ExpectedCommandTag))) {
            Write-Sample @{utc=$utc;event='identity_mismatch';pipeline_pid=$PipelinePid;attention=$true}; break
        }
        $ids = [System.Collections.Generic.HashSet[int]]::new()
        [void]$ids.Add($PipelinePid)
        do {
            $before=$ids.Count
            foreach ($process in $all) {
                if ($ids.Contains([int]$process.ParentProcessId)) {
                    $ancestor=$all | Where-Object ProcessId -eq $process.ParentProcessId
                    if ($ancestor -and $process.CreationDate -ge $ancestor.CreationDate) { [void]$ids.Add([int]$process.ProcessId) }
                }
            }
        } while ($ids.Count -gt $before)
        $processes = @()
        foreach ($process in $all) {
            if ($ids.Contains([int]$process.ProcessId)) {
                $live=Get-Process -Id $process.ProcessId -ErrorAction SilentlyContinue
                if ($live) { $processes+=@{pid=$live.Id;parent_pid=$process.ParentProcessId;
                    private_gib=[math]::Round($live.PrivateMemorySize64/1GB,3);
                    working_gib=[math]::Round($live.WorkingSet64/1GB,3);cpu_seconds=$live.CPU} }
            }
        }
        $os=Get-CimInstance Win32_OperatingSystem
        $memory=Get-CimInstance Win32_PerfFormattedData_PerfOS_Memory
        $free=[math]::Round($os.FreePhysicalMemory/1MB,3)
        $commit=[math]::Round(($memory.CommitLimit-$memory.CommittedBytes)/1GB,3)
        Write-Sample @{utc=$utc;event='sample';pipeline_pid=$PipelinePid;monitor_pid=$PID;
                      physical_available_gib=$free;commit_available_gib=$commit;
                      attention=($free -lt 4 -or $commit -lt 8);processes=$processes;
                      policy='passive_only_no_kill_no_restart_no_resource_change'}
    } catch {
        Write-Sample @{utc=(Get-Date).ToUniversalTime().ToString('o');event='monitor_error';attention=$true;error=$_.Exception.Message}
    }
    Start-Sleep -Seconds 15
}

```


## Independent post-run audit

After the seven stages finish, keep the frozen checkout and raw data intact. Restore the orchestration Python helper above as `../../t0019_pipeline.py`, but do not run its main again. The audit imports only its read-only identity functions. Set the same AI_TEST_ROOT, CXX, OMP_NUM_THREADS=8 and worktree-specific Git safe.directory environment. The raw audit asserts the original source HEAD and therefore runs on the frozen measurement checkout with this report copied into its report lane, before a report-only commit (or on a restored frozen checkout).

```powershell
python tools/repo/task.py lock --task T0019 --wait 60 cpu -- python bots/p_only/report/search_portfolio/audit_raw.py
python bots/p_only/report/search_portfolio/audit_aggregates.py
```

The scripts read existing matches/branches, verify identities, compare generated statistics and emit INDEPENDENT_AUDIT.json. They play no new games, export no models and write no task-board or main changes. Raw receipts remain in ignored data/build; the report receipt binds their aggregate SHA-256. Successful-reply latency excludes missing timeout replies. C08 two-team games use the separate planner: all280 games have PONLY counters but only260 have SEARCH/PLY2 lines. Supplemental PORTFOLIO per-turn denominators use the recorded400-turn games with a PORTFOLIO line; those turns are a denominator, not an emitted setting counter.

Completed-stage receipts must be preserved on any audit failure. Local audit setup corrections (compiler path, two-team counter-line expectation, absent settings dictionaries and reconstructed PORTFOLIO turn denominator) did not change any formal measurement or rerun a completed game.

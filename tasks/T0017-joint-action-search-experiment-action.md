## Goal

Code-only search experiment on the existing trained models (no retraining, no feature change, same depth and scoring; V off as the frozen heuristic baseline). In the family carriers generated by bots/p_only/tools/derive/make_families.py, with every change behind its own build setting and the current search as the default arm: (1) a bounded per-movement action portfolio (k-best complete assignments from the existing 8-mask DP: alternate targets, attack vs pickup, explicit wait vs pickup, gated own drops) for a small movement shortlist plus the incumbent, deduplicated by complete order; audit and fix moveIndex-only equality checks and wait/pickup serialization; (2) for C08, ply-2 predictions from each candidate's own settled successor instead of the reference plan's, with a diagnostic mode comparing both, exact-state caches and counters; (3) training.branch_collect candidates with two-unit, target, pickup/wait, drop and transport alternatives, explicit carrier-arm selection with binary verification, a candidate from another arm, and summary counts. Contract tests, reproducible profiles, docs/SEARCH_PORTFOLIO.md. Host evaluation is a separate dependent task.

## Done when

PR merged; production carriers byte-identical; flags-off family carrier replies equal the production carrier's on recorded games; contract tests for same-movement alternatives, serialization, thresholds/overkill, branch-specific P inputs, cache equality, root/history invariance and deadline fallback pass; both test suites pass; host task created with exact commands.

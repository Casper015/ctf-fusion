## Controlled experiment

Measured source: `9a78345172010a207fe89c54af12704b8cc3fddf`. Same 21,000 raw matches, layout-3 rebuild, 30,049,121 extracted rows, and exact legacy-column/label parity. Each run uses all 24,153,825 eligible training rows and 2,981,919 validation rows, with no row reduction or test-based fitting.

The XXL hidden widths are mover256, squad1024/256, act256 and target32. P3 adds the combat input block; the target feature schema remains unchanged.

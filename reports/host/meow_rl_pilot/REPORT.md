## Backup and limitations

- Backup `data/backups/meow_rl_pilot_20261015.tar.gz` (312,274,389 bytes, sha256 `8812af86e0a3bf52`) is on the host's own disk: an off-machine copy is still needed.
- The runs did not use `--keep-features`: the batch files hold no actor/value features, so the export cannot calibrate on the runs' own observations (`bots/meow_rl/calibrate.py` records calibration observations from fresh games with the frozen actors instead).
- No held-out evaluation pool was frozen with the run: the screens draw their opponents from a disjoint roster (`profiles/meow_rl_screen.json`).
- Receipt paths use Windows separators; this report normalizes them.

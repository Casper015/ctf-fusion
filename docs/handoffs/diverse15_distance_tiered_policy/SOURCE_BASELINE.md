# Source baseline and scope of this package

The initial source review inspected `34a83b0969098b46eeee4fd825ee639de7528b28`. It identified Windows binary stdout, an offline/runtime adapter mismatch, incomplete or stale deployment approval, missing score-tie features, insufficient family/map isolation, and unchecked native widths. Its findings were source review evidence, not new match results.

The current repository was fetched at `7bbeeb0d7eb1f7a974997e0aae9a095bc970e0ac`. The subsequent commit and README document fixes for those contracts, including `inference/adapter.hpp`, exact integer-artifact gating, feature spec v2, strict fixture/map holdouts and width checks. This package preserves them; it does not present the earlier defects as unresolved current findings. The full updated repository test suite was not rerun when preparing this handoff. The package's standalone tools were tested separately.

Before publication, the checkout was fast-forwarded to `93fa7e604ca9a05e48b8e04d787dcb387401fba8`. This adds `tools/host/capacity_bench.py`, a native size workload, synthetic model data and configurable `FUSION_MAX_WIDTH` with checks. The execution prompt now reuses this profiler and distinguishes its tier names from this proposal. No capacity timing was run while preparing this package. New default profiles remain to be selected from actual host evidence.

At that initial review, the repository reported no real-data trained model, integrated bot, Windows execution or target-host latency baseline. Later commits add roster tooling and host/SIMD capacity reports; those provide native-cost evidence, not a complete-bot deadline or neural strength result. The source baseline checked for this revision is `aa3fcc1`; subsequent documentation-only remote changes were preserved before publication. No model training or full-bot confirmation was independently rerun for this documentation update.

The training requirement is now an open, versioned opponent registry with no fixed 15-bot cap, separate from frozen evaluation panels and reserved OOD families. A panel of 15 remains an optional historical comparison budget. Open admission, hierarchical sampling, adaptive dispatch and CUDA integration are implementation tasks; publishing these documents does not enable or certify them.
